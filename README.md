# TypePair — أداة تنسيق الخطوط (تجريبي)

أداة لاستكشاف تركيبات الخطوط ومعاينتها.

## المزايا
- ستة أزواج خطوط منتقاة من مجموعة الخطوط المعتمدة (Geist وManrope وPoppins وGeist Mono)
- فلترة حسب النمط: حديث، تحريري، ودود
- معاينة في ثلاثة تخطيطات: واجهة رئيسية ومقال وبطاقة
- ضبط حجم العنوان وحجم النص بمزلقات
- مقارنة حتى ثلاثة أزواج جنباً إلى جنب
- حفظ الأزواج في التخزين المحلي ونسخ CSS جاهز
- واجهة ثنائية اللغة (العربية RTL / الإنجليزية LTR) مع مبدّل لغة

## التشغيل
```bash
npm install
npm run dev
npm run build
```
